# Passionate Designs Hub

Build a premium, modern, and highly visual website for "Passionate Interior Design & Studio" (also known as Passionate Interior), an established architecture and interior design firm based in Lucknow, Uttar Pradesh, India. 

The website should feature a sleek, dark/light toggle mode option, smooth animations, rounded architectural cards, and clean spacing.

Implement the following multi-page navigation structure using a top navbar and a sticky footer:

1. Home

2. About Us

3. Services

4. Portfolio Gallery

5. Contact Us

- HOME PAGE:

  * Hero Section: Title should be "Modern, Elegant, and Premium Interior Designs in Lucknow." Add a prominent Call-to-Action (CTA) button: "Book a Free Consultation" that links to the contact form.
